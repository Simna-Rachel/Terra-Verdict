# 🌍 TERRA VERDICT

**Can your choices save the world?**

A browser-based corporate sustainability simulator. You are the CEO of a global mega-corporation. Over 8 fiscal years, every decision moves three meters: 💰 Profit, 🌍 Planet and 👥 People. Let Planet or People hit zero and the game is over.

## Features
- Cinematic intro with a WebGL-rendered spinning Earth
- 8 crisis years, each with three choices and hidden trade-offs
- Advisor feedback (Dr. Maya Chen) after every decision
- Policy Blitz mini-game (sort good and bad policies against the clock)
- Main menu with Settings, How to Play, Achievements and About
- Difficulty modes, 8 achievements, and saved progress (localStorage)
- Procedural sound effects (Web Audio API, no audio files)

## Run it
Open `index.html` in any modern browser. No install or build step is needed.
An internet connection is required for the Google Fonts, background photos and Earth texture.

## Project structure
```
index.html          page structure
style.css           all styling
script.js           game logic, audio, menu and mini-game
assets/             Earth images used in the story and end screens
```

## Host it on GitHub Pages
1. Push these files to a repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then save.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
